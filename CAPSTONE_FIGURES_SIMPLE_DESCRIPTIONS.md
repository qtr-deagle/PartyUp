# PartyUp Capstone - All Figures Simple Descriptions

Figure 1: Landing Page - This is where the users can download the app and see the core matching feature (92% compatibility scores).

Figure 2A: Register Step 1 - This is where users create their account with email/password or OAuth (Google, GitHub).

Figure 2B: Register Step 2 - This is where users enter their name and date of birth for age verification and safety.

Figure 2C: Register Step 3 - This is where users select their 12 travel interests (Backpacking, Food, Adventure, etc.) - the foundation of our matching algorithm.

Figure 3: Discovery/Matching - This is where our AI algorithm shows users real-time compatible travel buddies with compatibility scores (92%, 85%, etc.) calculated from 5 factors.

Figure 4: User Profile - This is where users can view their verified badges, ratings, past trips, reviews, and travel interests selected during registration.

Figure 5: Trip Creation - This is where users post a new trip with destination, dates, budget, interests, and attract travel buddies.

Figure 6: Chat Interface - This is where users send real-time messages to their matches to coordinate and plan trips together.

Figure 7: My Trips Dashboard - This is where users view all their active, upcoming, and completed trips with member avatars and trip status.

Figure 8: Carpool/Vehicle Details - This is where users browse available cars for carpooling with owner ratings, daily rates, and booking options.

Figure 9: Booking/Payment - This is where users confirm their booking with cost breakdown, payment processing through Stripe, and trip details.

Figure 10: Admin Dashboard - This is where admins monitor system health with KPI cards (users, trips, revenue, safety incidents) and trip activity.

Figure 10B: Staff Dashboard - This is where safety moderators handle SOS activations, moderation queue, user violations, and emergency response.

Figure 11: Safety Features - This is where users see the SOS button, live location tracking, verification badges, and trust score for each traveler.

Figure 12: Reviews & Ratings - This is where users see community feedback, star ratings, and reviews from past travel buddies (social proof).

Figure 13: Mobile Responsive - This is the same features as desktop but optimized for mobile (375px width) with touch-friendly buttons and responsive layout.

Figure 14: Notifications - This is where users receive alerts for new matches, messages, bookings, trip reminders, and safety updates.
