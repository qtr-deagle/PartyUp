## 📋 Pre-Screenshot Checklist

Before capturing each screenshot:
- [ ] Close all extra browser tabs
- [ ] Clear browser history/cache (might affect appearance)
- [ ] Set zoom to 100% (Ctrl+0 or Cmd+0)
- [ ] Disable browser extensions that might overlay UI
- [ ] Use Incognito/Private mode (cleaner UI)
- [ ] Press F12 to toggle DevTools off (if open)
- [ ] Hover over interactive elements to show state (buttons, cards)
- [ ] For landing page: scroll to show full page depth
- [ ] For forms: make sure all fields fit without scrolling
- [ ] For cards: show multiple cards in stack to indicate "multiple matches"

---

## ✅ Post-Screenshot Checklist

After capturing each screenshot:
- [ ] Image is in high resolution (1920px width recommended)
- [ ] Text is legible when scaled down for presentation
- [ ] Colors are accurate (no color shift from screenshot tool)
- [ ] No personal user data visible (use realistic but non-identifying names)
- [ ] No error messages or warnings visible
- [ ] All important UI elements are visible (not cut off)
- [ ] Aspect ratio matches your presentation slide size
- [ ] File is saved in accessible format (PNG or JPG)
- [ ] Add annotation layer in PowerPoint/Figma AFTER capturing

---

## 💡 Pro Tips

1. **Capture Multiple States**: Take 2 versions of each page
   - One "plain" version (no interactions)
   - One with a highlighted element or hover state

2. **Consistency**: Use same browser, zoom, lighting for all screenshots

3. **Annotation Colors**: 
   - Red/Dark red for PRIMARY (high priority)
   - Yellow/Orange for SECONDARY (nice to mention)
   - Light blue for SUPPORTING (context only)

4. **Arrow Style**: Use 2-3px arrows with numbers (1, 2, 3) if showing multiple points

5. **Font Size**: Annotations should be readable at 70% scale (presentation size)
